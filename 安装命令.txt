# libclang 安装命令

## 方法 1：使用安装脚本（推荐）

```bash
bash /tmp/install_clang.sh
```

这个脚本会：
- ✅ 自动更新软件包列表
- ✅ 安装 clang、llvm、libclang-dev
- ✅ 验证安装成功
- ✅ 显示 libclang 库位置
- ✅ 提示下一步操作

---

## 方法 2：手动安装（单条命令）

```bash
sudo apt-get update && sudo apt-get install -y clang llvm libclang-dev clang-tools-extra
```

---

## 方法 3：分步安装（更详细）

```bash
# 1. 更新软件包列表
sudo apt-get update

# 2. 安装 clang 和 libclang
sudo apt-get install -y clang llvm libclang-dev

# 3. 验证安装
which clang
clang --version

# 4. 查找 libclang
find /usr -name "libclang*.so*" 2>/dev/null | head -3
```

---
